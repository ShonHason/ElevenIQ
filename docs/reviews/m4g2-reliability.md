# M4g2 — Multi-split reliability (plan 005 M4g2, ADR 004 §13.6)

Generated by `spikes/m4g2_reliability_review.py` from the committed measurements (`src/eleveniq/analytics/measurements/statsbomb_27.json`, K = 3200) and `data/processed/reports/m4g2_reliability_cells.json`. Both are checked value by value by `spikes/m4g2_reliability_reference.py --check-output`.

## Method

- Per split, each stint's matches go at random to two equal halves (odd count: a coin decides which half gets the extra match); one generator, `default_rng(20261007)`, draws in a fixed order; one assignment per split serves every cell.
- Per split and cell: half values demeaned within league × group, pooled Pearson r_k, Spearman-Brown; r_full = the mean of the corrected values over the splits.
- K starts at 200 and doubles until every judged cell's MC SE ≤ 0.002, capped at 3200. **K = 3200; cap reached: True.** Judged cells still above the target: ST `defensive_duel_success_pct`.
- Per-90 gated cells: MC SE median 0.0005, max 0.0032.
- MC errors are correlated across cells (one assignment per split), so a count of cells crossing 0.6 is not a count of independent events. Sampling error over players (SE ≈ 0.04) is unchanged: cells near 0.6 stay fragile.

## Odd/even vs multi-split

z = (odd/even − multi-split mean) / SD over the splits, 215 per-90 gated cells: mean +0.27, SD 1.05; |z| > 2: 13, |z| > 3: 2. Mean shift (multi-split − odd/even) -0.0078.

**Hypotheses (user, 2026-10-07):** alternating dates spread both halves over the whole season, so form, injuries and coach changes are shared (temporal balance), while random halves can cluster in time; home/away alternation alone would more likely lower r than raise it. No change here is "improved reliability": both methods estimate the same quantity, the new one with less split noise.

**Outcome of the test (stats-reviewer, 2026-10-07; 400 random splits with the engine's split functions; ADR 004 §13.6):**

- **The optimism is real:** the odd/even split hits every cell at once, so cell z values are correlated; allowing for that, the cross-cell mean z over random splits has SD 0.111, and odd/even's +0.25–0.27 has P ≈ 0.007.
- **Temporal balance: confirmed.** A time-balanced random split (randomised within consecutive match pairs) gives mean z +0.175, and odd/even sits inside that distribution; a first-half vs second-half split gives −0.87 (within-season drift is substantial).
- **Home/away: rejected.** A home vs away split gives z −0.07; odd/even halves are less home/away-balanced than random ones (mean |Δ home share| 0.29 vs 0.16), which pushes r down.
- **Consequence:** random splits count within-season drift as error, while for a season aggregate it is part of the true value, so multi-split r_full understates a season aggregate's reliability by about 0.004–0.008 on average (conservative). The method stands; a time-stratified random split is the alternative if a later ADR wants one.
