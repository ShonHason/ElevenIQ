## Method

- **Rows:** the 1,233 primary scored rows of the four 2015/16 pool leagues (1,201 complete, 32 partial, 0 `dna_incomplete`).
- **Distance** (ADR 004 §12.6, provisional): weighted squared Euclidean on local percentile / 100 over the metrics both rows have. **Family weights** (pre-registered): each family 1 / |F|, split equally among its shared members. **Equal metric weights**: each shared metric 1 / (number of shared metrics). Both decompose exactly into per-family contributions; a family with no shared metric in a pair contributes 0 to that pair.
- Every family-weight distance equals the reference spike's `pair_distance` within 1e-12 (156,961 same-group pairs, both orders).
- **Neighbours:** same group, any pool league, excluding the same `player_id`; k = 10; ties broken by the season key.
- **Overlap** = |top-10 A ∩ top-10 B| per row. Columns: mean overlap / 10, median, P10, min, share of rows with ≥ 7 shared, share with ≤ 4 shared.
- **Pure noise** (stats-reviewer, M4f3 review): independent uniform percentiles in each group's metric and family structure, with the group's row count; 5 seeded replicates, pooled. It is the reference for what the neighbour rule produces with no structure in the data.
- Quantiles are linear-interpolated (type 7). "RMS gap" = √d × 100, the weighted RMS local-percentile gap in points.

## 4. Partial rows as neighbours

A partial row misses one DNA ratio (`below_min_attempts`, ADR 004 §12.2); a pair involving it uses the metrics both rows have, with the family re-split. Expected = each row's 10 slots filled in proportion to the partial share of its candidate set. In-degree = the number of top-10 lists a row appears in. **Control** = obs / exp with the missing metric dropped for every row of the group, so the missing-data rule plays no part: what remains is where the partial players sit (they fell below the minimum attempts, so they are not typical rows).
